# Portafolio Web — Ezequiel Güiraldes

Portafolio web personal desarrollado para presentar mi perfil académico, habilidades técnicas, proyectos y currículum vitae.

## Tecnologías utilizadas

* **HTML5** — Estructura semántica y secciones del sitio.
* **CSS3** — Estilos minimalistas, variables de color, modo claro/oscuro y diseño adaptable (responsive).
* **JavaScript** — Interactividad del menú móvil, persistencia de tema en `localStorage`, validación de formulario y descarga de CV.
* **Figma** — Prototipado visual de la interfaz.

## Estructura del proyecto

Portafolio/
├── index.html                      # Página principal
├── css/
│   └── styles.css                  # Estilos y diseño responsivo
├── js/
│   └── main.js                     # Lógica e interacciones
└── assets/
    └── CV_Güiraldes-Ezequiel.pdf   # Currículum Vitae en PDF

## Funcionalidades principales

* **Modo Claro / Oscuro** con guardado automático de preferencia.
* **Diseño responsivo** adaptado a computadoras, tablets y celulares.
* **Descarga directa del CV** en formato PDF.
* **Secciones organizadas:** Inicio, Sobre mí, Habilidades, Proyectos, Educación y Contacto.

## Cómo visualizarlo

1. Cloná o descargá este repositorio.
2. Abrí `index.html` en tu navegador (o mediante una extensión como *Live Server* en VS Code).
